# 晶体突围

为 Agent Workbench 准备的轻量网页小游戏样例：用它验证 Agent 能否在有交互和规则的项目里完成一个可检查的改动，而不是只返回一段文本。

## 启动

从本目录运行：

```bash
python3 -m http.server 8000
```

浏览器打开 `http://localhost:8000`。使用 WASD/方向键或屏幕方向键移动，收集 5 颗晶体并避开巡逻障碍；按 `Space` 或点击“冲刺”触发技能。任务定义与验收标准保留在 `TASK.md`。

## 测试

需要 Node.js 20 或更高版本，不需安装 npm 依赖：

```bash
node --test
```

## 冲刺功能

冲刺沿当前方向移动；静止时沿上次方向，初始向右。持续 0.35 秒，速度为平时的 2.8 倍，期间短暂无视巡逻障碍；冷却 3 秒，界面显示冷却剩余时间。
# 冲刺功能

Space键与屏幕“冲刺”按钮均可触发技能：沿当前方向快速移动；不移动时沿上次方向，初始向右。技能持续 0.35 秒，速度为平时的 2.8 倍，冲刺期间短暂无视巡逻障碍；随后进入 3 秒冷却，界面显示剩余时间。
