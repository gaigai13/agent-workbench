# Agent 交付任务：实现冲刺技能

> 状态：参考实现已加入本仓库并通过本地测试。此文件保留原任务目标与验收标准，供演示和后续迭代对照；不代表该实现由真实外部 Agent 完成。

## 目标

在当前《晶体突围》小游戏中加入可由键盘和触屏触发的冲刺技能。Agent 完成实现后提交候选结果，由人检查改动和测试，再决定是否验收。

## 验收标准

1. 玩家可按 `Space` 或点击触屏冲刺按钮触发冲刺；沿当前移动方向冲刺，静止时沿上一次移动方向，初始方向为向右。
2. 冲刺持续 `0.35` 秒，移动速度为正常速度的 `2.8` 倍；期间与巡逻障碍重叠不会失败，冲刺结束后碰撞仍会失败。
3. 冷却为 `3` 秒，从冲刺开始计时；界面能看出可用/冷却状态及剩余时间，冷却中重复按键不能再次触发。
4. 重置或重新开始后，冲刺状态、计时和冷却全部回到初始状态，不遗留旧计时器。
5. 现有键盘与触屏移动、收集晶体、胜负判定和 60 秒倒计时保持正常。
6. `node --test` 通过；README 记录启动方式、操作方式和测试命令。

## 约束

- 使用现有原生 JavaScript 模块，不添加运行时依赖。
- 修改仅限当前游戏工作区；不得访问网络、写入工作区外文件或自动发布。
- 不改变既有胜负规则；若发现需求冲突，先记录并说明。

## 任务开始时的基线

游戏已经支持 WASD/方向键、触屏方向键、5 颗晶体收集、巡逻障碍碰撞、60 秒计时与重置；任务开始时尚无冲刺按钮、无敌状态或冷却逻辑。当前实现已满足上方验收条件，可从游戏源码检查。
